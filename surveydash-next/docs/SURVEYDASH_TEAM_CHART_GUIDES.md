# Team, chart composer and walkthrough refinement

The user's response-timeline screenshot is the visual baseline: white/neutral cards, a thin border, generous space, readable labels and a violet accent. The new chart composer uses the same real chart renderer as the dashboard. It replaces the miniature sketch picker and narrow drag palette in the add/edit flow. Dashboard cards and slide charts share source selection, question search, chart controls and a preview loaded from authenticated stored data. Empty sources remain empty; no example answers, fabricated trends or inferred choice options are added. Native SVG/HTML and the existing icon set provide the visuals without new dependencies.

The Surveyor page now lists workspace assignments across surveys, with name/@username search, status/survey filters, a refresh action and a scoped status confirmation. An identical full name does not merge accounts: actions use the assignment ID and survey owner. Deactivation stops that task's referral link, preserves old responses and leaves other tasks/workspaces unchanged. Reactivation rotates the referral token. Search also exists within the per-survey assignment panel. The authenticated read-only `/api/workspace/surveyors` endpoint refreshes the roster without resetting the search. It uses the same manager/workspace guard as existing assignment mutations and returns no payout or email fields.

Text and number questions can supply private chart widgets and slide charts. The server refreshes text/number slide distributions through the existing bounded breakdown helper. High-cardinality or long-text fields direct users to Data rather than displaying incomplete totals. Text-based chart templates can be reused privately. The existing public-share check continues to refuse raw text sources. Ordinary insights requests and the dashboard no longer ask for raw text samples.

## Walkthrough repair

The old guide inserted its coach through a React portal owned outside the dialog. The installed Radix DismissableLayer uses React-tree pointer/focus capture to recognize an inside interaction; DOM containment alone did not make the portaled coach a normal dialog child. The guide also disabled its primary button on the create-draft step, inserted coach content between fields, and had no recovery when a creation or preview dialog was manually closed.

`TourHost` now renders the coach as a real React child of the dialog. A client-only external store transports the instruction element; server snapshots are always empty, and subscriptions/content are removed on unmount. Fields scroll independently while the coach stays in the dialog footer. VisualViewport resize/scroll and animation completion update placement; a compact layout keeps controls visible with a small keyboard viewport. The explicit **Buat survei** coach action delegates to the real submit button, and the guide advances only after the existing successful-create event. Back does not return an existing draft to another creation. Closing a dialog returns to a reachable step. Missing sections expose Buka langkah and Skip; publication, invitations and clipboard writes are never automatic. Existing durable completion/skip preferences remain respected, and respondent pages still mount no tutorial.
